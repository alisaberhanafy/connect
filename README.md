# Connect WiFi Mobile App UI — V16

واجهة معاد تصميمها لتكون Mobile-first كتطبيق PWA على الهاتف:
- شاشة رئيسية مختصرة مناسبة للموبايل، مع مناطق لمس كبيرة.
- عرض مختلف على الكمبيوتر.
- شريط هوية علوي، الخدمات الأساسية، الدعم الفني، وأزرار التثبيت والمظهر.
- اختيار 6 ثيمات من لوحة سفلية مناسبة للموبايل.
- حفظ اختيار المظهر على جهاز المستخدم.
- PWA بوضع standalone واتجاه portrait، مع Service Worker وملفات خلفيات مخزنة للعمل دون اتصال (الصفحة فقط).
- روابط الدخول الأصلية كما هي.

## النشر
ارفع كل محتويات المجلد إلى جذر GitHub Pages، ولا تنسَ مجلدي `icons` و`backgrounds`.

## اختيار ثيم افتراضي للجميع
عدّل `theme-config.js`:
`defaultTheme: "neon", lockTheme: true, allowCustomerChoice: false`
ثم ارفع التعديل إلى GitHub.

ملاحظة: روابط بوابات المستخدمين نفسها تفتح في المتصفح/صفحاتها الخارجية؛ الواجهة الرئيسية هي التي تعمل كتطبيق PWA قابل للتثبيت.
